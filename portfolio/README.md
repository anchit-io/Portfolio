This repository contains the source code for my personal cloud engineer and DevOps portfolio website. It showcases my certifications, featured projects, technical skills, and professional experience.

## 🔗 Live Demo

Visit **[saumitra-rajput.github.io/portfolio](https://saumitra-rajput.github.io/portfolio/)** to see the live site.

## 🛠️ Tech Stack

- HTML5, CSS3, JavaScript
- Deployed via **GitHub Pages**
- Custom assets and styling

## 🚀 Local Development

To run this site locally:

1. Clone the repository:
   ```bash
   git clone https://github.com/saumitra-rajput/portfolio.git
   ```
2. Navigate to the project directory:
   ```
   cd portfolio
   ```
3. Open index.html in your browser.
