# Anchit Mishra — Infra Console Portfolio

A no-build, single-page portfolio styled as an ops/monitoring console, tailored to
Anchit's DevOps and cloud-infrastructure background. It pulls live public profile
stats and recent repositories for `anchit-io` directly from the GitHub API.

## Files

- `index.html` — page content and structure
- `styles.css` — all styling and layout
- `script.js` — live ticker, GitHub API fetch, copy-to-clipboard

## Publish with GitHub Pages

1. Create a repository and upload these three files (plus this README, optional).
2. In the repository, open **Settings → Pages**.
3. Select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
4. GitHub will provide a live URL within a minute or two.

No installation or build step is required — it's plain HTML/CSS/JS.

## Personalize further

- Swap in real repo links under the **Deployments** section if you want project
  cards to link straight to GitHub instead of just describing the work.
- The **GitHub** section auto-updates from the public API — no edits needed
  as your repos and follower count change.
